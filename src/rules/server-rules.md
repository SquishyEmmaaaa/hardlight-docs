# Server Rules

> **Hard Light is an 18+ English-speaking medium roleplay server. Users under 18 will be banned immediately.**

Rules apply at all times, including between rounds. Rules highlighted with \* are **always enforced**. Other rules are enforced upon receiving a player report.

If you have questions, use the Admin Help menu (F1 in-game or the AHelp button in the lobby), or ask on the Discord.

> **Rule 0:** Implementation and interpretation of the rules is at the sole discretion of the Admins. Admins are held accountable through the Admin Code of Conduct.
