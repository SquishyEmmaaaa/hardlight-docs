# Server Rules

```admonish warning
**WARNING: You must be 18 or older to play. Users under 18 will be banned immediately.**
```

Hard Light is an english speaking 18+ medium roleplay server.

## 0. Rule 0

Implementation and interpretation of the rules is up to the sole discretion of the Admins.

- Admins will instead be held accountable through use of the Admin code of conduct.

If you have any questions about these rules, please use the Admin help menu by hitting F1 in-game, or clicking the "AHelp" button in the lobby, or alternatively, ask for assistance on the discord.

```admonish note
**Hardlit enforcement:** Rules marked with 🔷 are enforced at all times. Other rules are only enforced upon receiving a user report.
```
