# Admin Overview

HardLight administration exists to protect a relaxed, fun environment for the community. The admin role is closer to a community host than a strict enforcer.

All staff conduct is governed by one standard: communicate clearly, correct behavior early, enforce consistently, and use punitive action only when correction fails or severity requires it.

> "...all admin policies and expectations are governed by this code of conduct standard."
