# Colonial Command

This page defines how admins should run Colonial Command characters in practice.

## Definition

CCO means Colonial Command Official and refers to admins playing Colonial Command characters.

Only admins may play Colonial Command characters.

## Core Standard

Colonial Command should be authority with restraint: professional, direct, and non-vindictive.

CCO presence should be request-driven, not passive observation. Stay off-station unless requested through reports, faxes, direct contact, or other active station requests.

## Authority and Presentation

CCO authority applies only while clearly presented as Colonial Command in-role.

Minimum expectation for active CCO authority:

- Proper Colonial Command ID
- Colonial Command uniform/outfit
- Clear identifying gear consistent with role
- Mindshield when applicable to role setup

If not in CCO presentation, do not exercise Colonial Command authority.

## In-Round Conduct Boundaries

- Do not turn OOC punishments into IC spectacle.
- Do not post role bans or other punishment outcomes into public IC framing.
- While acting as CCO, do not interfere with antag play unless required for self-defense or pre-approved event structure.
- Do not intentionally put your CCO character in harm's way just to create an intervention excuse.

## Epsilon and Military Clarification

Epsilon is not a death squad standard. It represents Colonial Command martial-law authority conditions.

Colonial Command is the civilian branch. The Colonial Navy is the military branch and is separate, with military involvement treated as exceptional rather than routine.

## Practical Workflow

- Set up your character and intended tools before deployment to station.
- If appearing in a non-CCO social or vacation mode, you may roleplay the character but have no Colonial Command authority.
- Keep actions documented when CCO involvement materially changes round outcomes.
