# Admin Policy

Standards and guidelines that all HardLight administrators must follow.

## Core Principles

- **Admins serve the players.** The admin role exists to ensure a fair and enjoyable experience for everyone, not to exercise personal power.
- **Consistency matters.** Identical situations should receive identical responses, regardless of who the player is.
- **Transparency where possible.** When taking action, admins should explain why whenever it doesn't compromise other players' experiences (e.g., revealing antag info).

## Handling Ahelps

1. Respond to ahelps in a timely manner. If a situation cannot be addressed immediately, acknowledge it so the player knows it was received.
2. Remain neutral until you have heard both sides.
3. Check the player's history before deciding on action.
4. Document all significant actions taken.

## Actions Admins May Take

| Action | When Appropriate |
|:-------|:----------------|
| Verbal warning | Minor or first-time infractions |
| Note on record | Any infraction worth logging, even without punishment |
| Kick | Immediate disruption that needs to stop |
| Temporary ban | Repeat or moderate rule violations |
| Permanent ban | Severe violations or ban evasion |
| Job ban | Misuse of a specific role |
| Smite / IC punishment | Roleplay-appropriate in-round consequences for IC infractions |

## Things Admins Must Not Do

- Use admin tools to benefit themselves or friends in-round.
- Reveal another player's real identity or account information.
- Carry out personal vendettas against players.
- Take permanent punitive action without documentation and, where required, senior admin review.
- Abuse the smite or event tools for entertainment at a player's expense.

## Admin Conduct Out-of-Game

Admins represent HardLight in public spaces (Discord, forums, etc.). Conduct unbecoming of an admin in these spaces is subject to the same review process as in-game misconduct.

## Accountability

Admin actions may be reviewed by senior staff at any time. If a player believes an admin acted improperly, they should use the [Appeal Process](appeal-process).
